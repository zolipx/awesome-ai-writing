# 中文风格保持评审量表

本量表只衡量候选文本对原创输入的**风格和叙事功能**的保存，并不判断其是否“像”任何现实作者，也不将“去 AI 味”视为检测规避。

## 必须保留的叙事材料

| 编号 | 材料点 |
| --- | --- |
| M1 | 叙述者从省城回到县城西边小站；傍晚、雨后地面与灯光构成开篇场景。 |
| M2 | 父亲的蓝布棉袄、黑伞，以及只问“饿不饿”的克制见面。 |
| M3 | 家中萝卜烧豆腐；叙述者辞职未明说；父亲以“慢慢找，先把身子顾好”回应。 |
| M4 | 清早送行；父亲把牛皮纸包塞进行李、替叙述者拉好拉链。 |
| M5 | 车开后父亲站在雨地、伞尖点地、棉袄下摆被风吹起，慢慢走向售票窗。 |
| M6 | 结尾纸包里是两个温热烧饼。 |

## 风格维度

| 维度 | 5 分 | 3 分 | 1 分 |
| --- | --- | --- | --- |
| 叙述视角与时序 | 第一人称、回忆性时序完整，叙述位置稳定。 | 偶有解释或跳跃，但主线还在。 | 视角混乱、改成建议/概述或改变事件顺序。 |
| 克制亲情 | 情感主要通过动作、停顿、物件和未说出口的话显现。 | 有少量直抒，但仍有具体细节支撑。 | 直接煽情、心理评判过多或变成鸡汤。 |
| 具体意象 | 关键物件和环境细节被保留，且服务于叙事。 | 保留部分细节，或替换为泛化说法。 | 大量删去或新增无根据的场景、物件和象征。 |
| 句法节奏 | 长短句交替自然，段落留有停顿，不刻意堆砌修辞。 | 基本通顺，但有模板化并列或解释过密。 | 生硬翻译腔、口号化、营销语或过度整齐的清单。 |
| 中文自然度 | 用词、标点、语序与现代中文散文相称。 | 个别搭配生硬。 | 明显英语规则硬套、外来术语或不自然的改写痕迹。 |
| 事实与细节保真 | M1–M6 均在且没有材料性新增。 | 仅有一处轻微省略/弱化。 | 多处遗漏、错置或新增关键事实。 |

## 风格漂移标签

评审可从下列标签中多选，并用候选中的短语举证：`过度解释`、`直接煽情`、`鸡汤化`、`模板化清单`、`现代口语过强`、`翻译腔`、`无根据新增`、`关键细节遗漏`、`叙述视角漂移`。
