Movie companies sometimes build sets instead of using real places for a few simple reasons:

- Control: A set gives them full control over how everything looks and feels. That matters if the story is in a made-up world or they need a very specific mood.

- Cost: Real locations are not always cheaper. Renting a place can be costly, especially for a long time. They might have to pay to use it, and pay again to change it to fit the story.

- Logistics: Real places can be hard to work in. There can be crowds, noise, and other distractions that make shots hard to get. The crew might not have what they need there, like electricity, water, or special equipment.

- Safety: Real places can have hazards like traffic, unstable ground, or bad weather. A set is a controlled space, so those risks are smaller.

Building sets can cost more at the start, but it can be cheaper in the long run because the filmmakers have more control and are less likely to face delays or surprise costs.
