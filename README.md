# Awesome AI Writing

一个面向中文与英文创作者的开源项目索引，集中收集 **AI 小说、长篇叙事、AI 写作工作台、故事生成、写作 Agent、Prompt/工作流**，以及 **去除 AI 味道、改善文本自然度的人类化工具**。

> 这是一个链接目录，不复制、镜像或打包被收录项目的源码。请在使用前自行检查项目的许可证、隐私政策、依赖和维护状态。

## 去除 AI 味道与文本人类化

## 收录标准

- 项目必须有公开可访问的代码、文档或 Skill 仓库链接。
- 优先收录有明确用途、可运行说明、许可证或活跃维护记录的项目。
- 收录描述只做导航，不代表本项目维护者为其背书。
- 不收录明显窃取内容、恶意软件、虚假检测保证或违反平台规则的项目。
- 项目状态会变化；提交 PR 时请补充项目当前用途、许可证和最后维护情况。

## 提交项目

请通过 [Issue 模板](https://github.com/zolipx/awesome-ai-writing/issues/new?template=add-project.md) 或 Pull Request 提交。请提供：

1. 项目完整公开链接
2. 项目所属类别
3. 一句话功能说明
4. 主要语言或运行方式
5. 许可证（如能确认）
6. 为什么它对 AI 小说或 AI 写作有帮助
